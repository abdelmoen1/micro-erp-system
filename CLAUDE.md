## Development Standards

- Read and follow the relevant installed skills
  before starting a task.
- For UI work, use the frontend-design skill
  and follow our established brand identity.
- For React work, follow the installed React
  best practices and web design guidelines.
- For Laravel work, follow the project's existing
  architecture and Laravel-specific guidelines.
- Inspect existing code before making changes.
- Avoid generic AI-generated visual patterns.
- Reuse existing components and dependencies.
- Run relevant tests and report actual results.
- Never deploy, commit, or push unless requested.
